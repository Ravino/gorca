# gorca configuration reference

The file is `$XDG_CONFIG_HOME/gorca/gorca.toml` (default `~/.config/gorca/gorca.toml`), or the
path given by `--config=PATH` or `GORCA_CONFIG`. It is reloaded when it changes, except
`[speech] backend`, which needs a restart.

The listing below is generated by `gorca config print-default` from the settings table, so it
lists every key. `gorca config check` reports problems in your file.

## Speech in another language

`[speech] language` is the language code sent to the speech server. Empty means the language
of your locale (`LC_ALL`, `LC_MESSAGES`, then `LANG`; `ru_RU.UTF-8` gives `ru`), and `en` when
there is none. `output_module` and `voice` are sent only when set.

Russian with speech-dispatcher:

```toml
[speech]
backend = "ssip"
language = "ru"
output_module = "espeak-ng"   # or "rhvoice"
voice = ""                    # optional, a voice name your module offers
```

Russian with voicego (it accepts the same `SET self LANGUAGE`, `OUTPUT_MODULE` and
`SYNTHESIS_VOICE` commands):

```toml
[speech]
backend = "voicego"
language = "ru"
voice = ""                    # optional, a voice name from your voicego engine
```

## Editing feedback

`[editing]` tunes what gorca says around the caret and the clipboard.

- `announce_clipboard = true` says "copied", "cut", "pasted", "undo" or "redo" (in the speech
  language) after Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z and Ctrl+Y (also Ctrl+Insert, Shift+Delete,
  Shift+Insert and Ctrl+Shift+Z) in an editable field. Each one is confirmed by what the text
  does and never claimed without evidence: "cut" needs the selected text to be deleted, "pasted"
  needs text to be inserted (and still reads it: "pasted, some words"), "undo" and "redo" need
  the text to change (one confirmation per key, and nothing in a widget that cannot undo, such as
  a GTK 3 entry), and "copied" needs a selection to exist (copying changes nothing that could
  confirm it). The keys themselves are never grabbed: they always reach the application. In
  browse mode Ctrl+C is the selection-model copy and is not affected.
- `boundary` is what an arrow, Home or End key does when the caret cannot move, at the start or
  end of a line or field. Like `[speech] caps` it is a list of independent options:
  `"cue"` (the default) asks the cue sink for a short boundary sound (until the sound theme
  exists the cue is silent, so a boundary key says nothing); `"say"` speaks a short word, "start"
  or "end" for Home, End and any key in a one-line field, "top" or "bottom" for the other keys
  of a text view (Russian: "начало", "конец", "начало текста", "конец текста"). Write them
  together as `["cue", "say"]` or `"cue+say"`; `"off"` or `[]` does nothing. `"repeat"` is the
  old behaviour (read the character, word or line under the caret again) and may be combined
  too. Terminals honour the setting the same way (start and end only).
- `word` is how coarse a word is when a word is read (Ctrl+Left and Ctrl+Right, the current-word
  commands, terminal review). `"fine"` is the caret word rule: letters, digits and `_` are a word,
  every other character a word of its own, so `--color=auto` has five stops. `"medium"` keeps
  option tokens, identifiers and file names whole (`--color=auto`, `foo_bar`, `file.tar.gz`,
  `user@host`, `10:30`; the joiners `- . = : @ ~` join when a letter or digit follows) while a
  slash, a quote, a comma or a trailing dot stay words of their own. `"coarse"` is everything
  between blanks. `"auto"` (the default) lets the application choose: a terminal reads medium
  words, every other editor fine ones. The words move with the application's own caret keys; this
  setting changes what is spoken, not where the caret lands.

## Default configuration

```toml
# gorca settings: every key at its default. Delete what you do not change.
# Keymap overrides go in [keymap.<context>] tables (see docs/config-reference.md).
schema = 1

[keyboard]
# Key bindings preset. (one of "nvda" or "orca")
preset = "nvda"
# Keyboard layout of the preset (keypad review keys on the desktop layout). (one of "desktop" or "laptop")
layout = "desktop"
# Key names that act as the gorca modifier. (list of strings)
modifiers = ["Insert", "KP_Insert", "Caps_Lock"]
# Drop Caps_Lock as a modifier when it switches keyboard layouts. (true or false)
caps_lock_layout_guard = true
# Window in milliseconds for double and triple key presses. (integer 100 to 2000)
multi_press_ms = 500
# Ignore a repeat of the same key within this many milliseconds. (integer 0 to 100)
double_tap_guard_ms = 15
# Which key presses cancel speech. (one of "non-modifier" or "never")
interrupt = "non-modifier"
# Control stops speech. (true or false)
stop_speech_on_control = true
# Shift pauses and resumes speech. (true or false)
pause_speech_on_shift = true

[keymap]
# Use only the [keymap.*] tables instead of layering them over the preset. (true or false)
replace_preset = false

[speech]
# Speech rate; 50 is the server default. (integer 0 to 100)
rate = 50
# Speech pitch; 50 is the server default. (integer 0 to 100)
pitch = 50
# Speech volume; 100 is the server volume. (integer 0 to 100)
volume = 100
# How much one rate, pitch or volume command changes the level. (integer 1 to 25)
rate_step = 5
# Synthesis voice name; empty is the server default (SSIP SYNTHESIS_VOICE). (string)
voice = ""
# Speech language code such as "ru"; empty is derived from LC_ALL/LC_MESSAGES/LANG, else "en". (string)
language = ""
# Speech-dispatcher output module such as "espeak-ng" or "rhvoice"; empty is the server default. (string)
output_module = ""
# Speech server: voicego with speech-dispatcher fallback (auto), voicego only, or speech-dispatcher only (ssip); the --speech flag wins; needs a restart. (one of "auto", "voicego" or "ssip")
backend = "auto"
# How much punctuation is spoken. (one of "none", "some", "most" or "all")
punctuation = "some"
# How a capital letter spoken alone is announced: any of "pitch", "word" ("cap" before the letter) and "sound" (earcon; not working yet, planned with the audio cue sink), for example ["pitch", "word"]; [] is none. (list of strings)
caps = ["pitch"]
# How far the pitch of a capital moves from the voice, in steps of the 0 to 100 pitch setting like NVDA (needs "pitch" in caps). (integer 0 to 100)
caps_pitch_change = 30

[echo]
# Speak each typed character. (true or false)
typed_characters = true
# Speak each typed word. (true or false)
typed_words = false
# Speak command keys such as Ctrl+S. (true or false)
command_keys = false
# Speak text inserted by paste or autocomplete. (true or false)
inserted_text = true

[editing]
# Say "copied", "cut", "pasted", "undo" or "redo" after Ctrl+C, X, V, Z or Y in an editable field, when the text shows that it happened (copy only with a selection). (true or false)
announce_clipboard = true
# What an arrow, Home or End key does when the caret cannot move: any of "cue" (a boundary sound; silent until sounds exist) and "say" (a short word: start, end, top, bottom), for example ["cue", "say"]; [] or "off" is nothing; "repeat" reads the unit under the caret again. (list of strings)
boundary = "cue"
# How coarse a word is: fine (letters and digits, each punctuation mark apart), medium (option tokens like --color=auto, identifiers and file names stay whole; slashes and other punctuation separate), coarse (everything between blanks); auto lets the application decide (terminals use medium). (one of "auto", "fine", "medium" or "coarse")
word = "auto"

[text]
# Say all moves the caret as it reads. (true or false)
say_all_moves_caret = true
# Caret events within this many milliseconds of an edit count as part of it. (integer 20 to 1000)
caret_edge_ms = 100
# Caret events later than this many milliseconds after a key are not announced as a move. (integer 100 to 2000)
caret_late_ms = 400

[browse]
# Read a web page automatically when it finishes loading. (true or false)
say_all_on_load = true
# Say the description of a web control after a short pause. (true or false)
description_pause = true
# Build a browse-mode view of web pages; false follows the focus instead, as for a code editor. (true or false)
enabled = true
# The mode a web page starts in: browse or focus. ("browse" or "focus")
mode_default = "browse"

[terminal]
# Wait this many milliseconds for terminal output to settle before speaking. (integer 10 to 200)
settle_ms = 30
# Output longer than this many lines is summarised instead of read. (integer 4 to 400)
burst_lines = 40
# Line endings that mark a shell prompt. (list of strings)
prompt_markers = ["$ ", "# ", "% ", "> ", "❯ ", "» "]
# Regular expression that matches a prompt; empty uses prompt_markers only. (string)
prompt_regex = ""
# Regular expression for lines never to speak, such as password prompts; empty is none. (string)
secret_regex = ""

[verbosity]
# How much detail is spoken. (one of "brief", "normal" or "verbose")
level = "normal"
# Full or brief confirmations of settings changes. (one of "full" or "brief")
confirmations = "full"
```
