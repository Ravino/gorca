# M1 live checklist: command layer

Run on the real GNOME 48 desktop with `tools/gorca-toggle.sh` (Super+Alt+G). gorca must be the
only screen reader (with Orca running it says once that commands are unavailable and keeps
reading focus). The gorca key is Insert (also KP_Insert with Num Lock off) and Caps Lock, unless
Caps Lock switches your keyboard layout. Settings: `~/.config/gorca/gorca.toml` (missing is fine;
`gorca config defaults` prints everything, `gorca config check` reports problems).

| Step | Expected |
|---|---|
| Tap Insert once, Caps Lock stays as it was | nothing is spoken, Caps Lock does not toggle |
| Double-tap Insert quickly | Insert reaches the application (a second tap within the GNOME repeat delay) |
| Insert+Tab | where am I: application, window, container with position, object; twice: description; three times: spelled name |
| Insert+T | window title (twice: spelled) |
| Insert+F12 | time (twice: date) |
| Insert+X | repeats the last spoken text |
| Control | speech stops at once, the Control key still works in the application |
| Shift tap (alone) | pauses; again resumes |
| Insert+S | "speech off"; again "speech on" |
| Insert+Ctrl+Up / Down / Right / Left | rate 55 / rate 50 / pitch / rate; the confirmation is spoken at the new value |
| Insert+2, 3, 4 | typed characters / words / command keys on or off |
| Insert+Shift+V | verbosity cycles brief, normal, verbose |
| Insert+1 | learn mode: every key is described, not run; Escape or Insert+1 leaves; a minute of silence leaves |
| Insert+F2, then a key | the key (even Insert+X) reaches the application, then commands work again |
| Edit `gorca.toml` (for example `[speech] rate = 70`) and save | "settings reloaded" within a second; a typo says how many problems, Insert+Ctrl+Shift+R reads them |
| Insert+Ctrl+R | runtime changes are dropped, file reloaded |
| Insert+Ctrl+C | runtime changes are written into the file (comments kept); a file edited meanwhile is not overwritten |
| `gnome-shell --replace` (or log out/in of the shell) | within 2 s: "keyboard commands restored" after one "unavailable" |
| Start Orca first, then gorca | one announcement that commands are unavailable; focus is still read |

Latency gates K2, K2s, K3, K4: `bench/e2e/run.sh m1-r1 --reader daemon:<abs>/target/release/gorca,--impersonate-orca --reader-env GORCA_M1=1`.
