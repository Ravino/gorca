# M8 live checklist: Firefox browse mode at NVDA parity

Run on the real GNOME 48 desktop with `tools/gorca-toggle.sh` (Super+Alt+G), your normal Firefox,
Orca off, NVDA keys preset (`preset = "nvda"`). The gorca key is Insert (and Caps Lock unless it
switches your layout). Everything in `docs/plan/checklists/M7a.md` still applies; this list is only
what M8 added or changed. Spec: `docs/plan/m8-spec.md`. Scripted gate: `tests/web/m8/run_m8.sh`
(318 steps; the status of each is in `docs/reports/m8-gaps.md`).

Compare every row with what NVDA says for the same keys on the same page. Note where gorca is
slower, louder, wrong, or silent. Pages to use: the corpus in `tests/web/m8/pages/` (open with
`file://`), a Wikipedia article, a GitHub repository page, a web mail, a news article, a page with
a cookie dialog.

## Quick navigation: names, role words and counts

| Step | Expected |
|---|---|
| F / E on a labelled field | "edit" (or "check box" ...), then the label, the state or value: "Search term, edit, blank" |
| X / R / C | check box / radio button / combo box with its label and state ("not checked", "checked") |
| L onto a list | "list with 3 items", then the first item |
| T onto a table | caption, "table with 3 columns and 4 rows", then the first row |
| Q onto a block quote | "block quote", then the text |
| D (landmarks) | the name and the kind: "Primary navigation navigation landmark"; unnamed sections are skipped |
| O | application / dialog / embedded object: "Calculator widget application" |
| S | "separator" |
| Moving out of a list, table or quote with the arrows or a letter key | "out of list" (or table, block quote) in front of the next line |
| Entering a landmark | its name and kind once; leaving is silent |

## New keys

| Step | Expected |
|---|---|
| `,` (comma) inside a list, table, quote or landmark | the cursor goes to the first line after it, with "out of list"; at the end of the page "bottom" |
| Shift+`,` | the start of the container, announced like a quick-nav hit |
| `,` outside any container | "Not in a container" |
| N | skips a block of links (a menu) to the next text; "no more text after a block of links" |
| P | next paragraph of text |
| A | next inserted, deleted or commented text |
| W | next node in an invalid state that is not a form field (spelling errors inside text are NOT found: Firefox gives them as text attributes) |
| gorca+Shift+Space | "single letter navigation off": H, K, F ... now reach the page (type in a search box that is not a field, use site shortcuts); arrows still work; again: "on" |
| Ctrl+Down / Ctrl+Up | next / previous paragraph (a line of text, not a soft-wrapped line) |
| Alt+Down / Alt+Up | next / previous sentence, only the sentence is spoken |

## Tables

| Step | Expected |
|---|---|
| Down in a table | one row per line: "cell cell cell" |
| Ctrl+Alt+Right / Left | next / previous column; the column header is said when it changes |
| Ctrl+Alt+Down / Up | next / previous row; the row header is said when it changes |
| At an edge | "Edge of table"; outside a table "Not in a table cell" |
| Ctrl+Alt+Home / End / PageUp / PageDown | first / last column / row |
| gorca+Ctrl+Alt+Left / Up | read the row / the column |
| A cell with rowspan or colspan | moves to the cell after the span |

## Forms and modes

| Step | Expected |
|---|---|
| Tab or click onto a radio button, a tab, a menu item, a list box option | "focus mode"; the arrows change the selection. A list box says its name first: "Toppings list box, Cheese selected" |
| Tab onto a grid cell (ARIA grid) | "focus mode" |
| Focus on a check box | "Gift wrap, check box, not checked" |
| Space on a check box in browse mode | only the new state: "checked" (no second "not checked" first) |
| Focus on a toggle button | "Watch, toggle button, not pressed" |
| A button with aria-expanded | "collapsed" / "expanded" |
| Focus onto `role=application` | "focus mode"; Escape does not leave; gorca+Space does |
| Focus into a modal dialog | the dialog's name and "dialog" in front of the field, once per dialog (not again for the next field) |
| Aria-modal dialog open | Down, H, K stay inside the dialog; Escape / closing returns to the opener |
| A required field with help text (aria-describedby) | KNOWN GAP: "required" is spoken; the help text may follow a moment later or not at all |

## Selection

| Step | Expected |
|---|---|
| Shift+Right / Left | "W selected" / "W unselected" (the character) |
| Ctrl+Shift+Right / Left | the word, selected / unselected |
| Shift+Down / Up | the lines, selected |
| Shift+Home / End, Ctrl+Shift+Home / End, Shift+PageUp / PageDown | selects to there |
| Ctrl+A | "all selected" |
| Ctrl+C after selecting inside one paragraph | Firefox copies the text (gorca mirrors single-text-node selections into the page); paste somewhere to check |
| Ctrl+C after a selection over several elements | KNOWN GAP: only a selection inside one text node reaches the clipboard; gorca+C (read the clipboard) does not exist yet |

## Live regions

| Step | Expected |
|---|---|
| A chat or status line that updates (aria-live polite) | the new text, when you are idle, never interrupting |
| An error banner (`role=alert`) | spoken at once, interrupting |
| A progress or log area | only the new line |
| The same message again within 10 s | not repeated |
| A page that floods updates (a ticker) | a few messages, then "N updates in <region>" at most every 5 s; keys still answer at once |
| A hidden or background-tab region | silent |

## Pages that change

| Step | Expected |
|---|---|
| A single-page-app route change (click a nav link) | the new heading / title is spoken, not the old view |
| Infinite scroll appends rows | silent; the new rows are reachable with K / I / Down |
| A list that the page re-renders in place while the cursor is in it | the cursor stays on the same line (position restore); only the toast / status speaks |
| A same-page link (skip link, table of contents, `#id`) with Enter | the cursor follows to the target and reads it |

## Tab

| Step | Expected |
|---|---|
| Move the cursor with arrows to the middle of a page, press Tab | focus goes to the first focusable element AFTER the cursor, not the first on the page (gorca moves Firefox's caret with the cursor so Firefox starts Tab there). UNVERIFIED in the scripted rig, which cannot type Tab into the page: report what happens |

## Not in M8 (known, do not report)

The elements list (gorca+F7) and find (gorca+Ctrl+F) are not implemented (no dialog UI yet); the
button text shown in a line is the visible text, not the aria-label; earcons for mode changes; the
expanded-popup Escape rule; embedded `<object>` elements are not found by O.
